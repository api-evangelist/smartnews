# SmartNews

SmartNews is a news-discovery company (Atomico portfolio) that operates the SmartNews Ads platform and publishes the **SmartNews Marketing API (v3)** — a REST API for programmatically managing advertising campaigns, ad groups, ads, media files, custom audiences, conversion pixels, and Business Manager product catalogs, plus an Insights API for performance reporting. Auth is OAuth 2.0 bearer (JWT).

- Website: https://www.smartnews.com
- Developer portal / OpenAPI reference: https://ads.smartnews.com/developers/
- Official API spec repo: https://github.com/smartnews/smartnews-ads-advertising-api-spec

Enriched by the API Evangelist pipeline: verbatim OpenAPI (46 operations), plus authentication, conventions, error catalog, data model, lifecycle, changelog, conformance, rate limits, candidate MCP tools, agent skills, security.txt / domain-security / vulnerability-disclosure, and an agentic-access profile.
