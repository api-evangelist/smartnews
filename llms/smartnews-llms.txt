# SmartNews

> SmartNews operates the SmartNews Ads platform and the SmartNews Marketing API
> (v3), a REST API for programmatically managing advertising campaigns, ad groups,
> ads, media, custom audiences, conversion pixels and Business Manager catalogs,
> with an Insights API for reporting. Auth is OAuth 2.0 bearer (JWT).
