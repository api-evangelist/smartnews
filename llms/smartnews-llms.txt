# SmartNews

> SmartNews operates the SmartNews Ads platform and the SmartNews Marketing API
> (v3), a REST API for programmatically managing advertising campaigns, ad groups,
> ads, media, custom audiences, conversion pixels and Business Manager catalogs,
> with an Insights API for reporting. Auth is OAuth 2.0 bearer (JWT).

## APIs
- [SmartNews Marketing API — developer portal](https://ads.smartnews.com/developers/): OpenAPI 3.0 reference (v3.0.1), base https://ads.smartnews.com/api/ma/v3
- [SmartNews Ads Conversion API](https://help-ads.smartnews.com/en/item-5499/): server-to-server conversion event ingestion, base https://log.smartnews-ads.com — no OpenAPI published
- [Getting started](https://help-ads.smartnews.com/en/item-4207/): first campaign via the Marketing API
- [Ads API Terms of Service](https://ads.smartnews.com/developers/tos-en.html)

Access is gated: an existing SmartNews Ads account plus an approved Developer
Application Form is required, one developer app per organization. Marketing API
v2 is disabled (410 Gone); v3 is current. There is no sandbox for the Marketing
API — only the Conversion API publishes a staging host.
